## The inversion

Nearly every agent framework lets the agent call the provider. The completion then exists only in
the agent's memory, so the log can describe what happened but never rebuild it. Re-running is the
best on offer, and a re-run drifts.

Here the **host** performs the call on the harness's behalf. The completion passes through the host
on its way back and lands in the journal as a record. Look for the arrow to the provider: it leaves
the host, and the sandbox has none.

## What that buys

<CardGrid>
  <Card title="Replay costs nothing" icon="rocket">
    Recorded completions are served from the log, so reconstruction is the same bytes rather than a
    similar answer. Zero provider calls, enforced in the controller and covered in CI.
  </Card>
  <Card title="Fork is not a re-run" icon="random">
    Children inherit the parent's prefix and diverge independently, so a fan-out starts from
    identical state at no model cost.
  </Card>
  <Card title="Placement is checked first" icon="approve-check">
    A harness declares what it needs to survive a resume and a runtime declares what it offers.
    Impossible pairings are refused **before** compute is provisioned, so the system degrades
    honestly instead of resuming wrong.
  </Card>
</CardGrid>

## Everything it does, on a real cluster

A plain Deployment and a PersistentVolume: no substrate, no memory snapshot. A turn, a second turn,
a free replay, a two-way fork, suspend and resume, then the pod is deleted and a different pod picks
the session up mid-conversation.

## Build on it

Three contracts. One neutral wire form with a Go SPI, and `Event` is shared by the log and the
harness stream, so what is journaled is exactly what the harness emitted.

<CardGrid>
  <Card title="Sessions" icon="seti:config">
    ```
    CreateSession   Exec      Fork
    GetSession      Replay    Suspend
    ListSessions              Resume
    ```
  </Card>
  <Card title="Harness" icon="seti:robot">
    ```
    Describe  the static contract
    Run       drive one turn,
              emitting typed events
    ```
  </Card>
  <Card title="Runtime" icon="seti:shell">
    ```
    Create    Restore   Stop
    Snapshot  Fork      Status
              Capabilities
    ```
  </Card>
</CardGrid>

Three runtimes ship. **`runtime/local`** is filesystem-only and refuses a memory-snapshot harness
rather than resuming it wrongly. **`runtime/remote`** attaches to a harness you are already running,
so your agent is registered by address rather than compiled into the server. **`runtime/substrate`**
runs both capability tiers against a real cluster on every pull request, on gVisor and on a micro-VM.
Kata, Cloud Hypervisor, and plain pods fit the same SPI. No provider SDK appears anywhere, and CI
asserts the core links no backend vendor.

```bash
go install github.com/aramase/agentsessions/cmd/agentctl@latest
```

Signed archives and container images are on the
[latest release](https://github.com/aramase/agentsessions/releases/latest).

:::caution[Pre-1.0, and not yet secured]
No authentication, authorization, or transport security. `IdentityRef` is recorded as provenance and
never enforced, `project` is a filter rather than a tenancy boundary, and `DeleteSession` and
`Cancel` are declared in the proto but not implemented. `agentsessions.v1` is a proto namespace, not
a stability promise.
:::
